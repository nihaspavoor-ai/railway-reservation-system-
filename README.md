Railway Reservation System (Python)

Description

A simple console-based Railway Reservation System developed in Python. It allows users to check seat availability, view ticket details, and cancel reservations.

Features

- Check available seats
- View ticket using Booking ID
- Cancel ticket and update seats
- Basic input validation

Technologies

- Python 3
- Dictionary for data storage

How to Run

1. Clone the repository:
   git clone https://github.com/your-username/railway-reservation-system.git
2. Open the folder
3. Run:
   python main.py

Menu

1. Check Availability
2. View Ticket
3. Cancel Ticket
4. Exit
